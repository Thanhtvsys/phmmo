# 🚀 Thanhtvsys Repo

Hệ thống quản lý và phân phối Tool MMO chuyên nghiệp cho iPhone Jailbreak.

## 📦 Các gói chính
* **PHMMO-Tool**: Tool backup/restore và reset data chuyên dụng.
* **Root Access Fixed**: Helper được cấp quyền Root tối thượng.

## 🛠 Cách sử dụng
1. Mở Sileo hoặc Cydia.
2. Thêm nguồn: `https://thanhtvsys.github.io/phmmo/`
3. Cài đặt gói **PHMMO-Tool**.
